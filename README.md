## 생성형 AI 사용 내역 (없으면 "없음")
- 질문 요지 : Intl.DateTimeFormat의 정의와 사용 예
- 답변 요약 : Intl.DateTimeFormat은 자바스크립트의 표준 내장 객체 중 하나로, 언어(Locale)와 형식(Options)에 맞춰 날짜와 시간을 보기 좋게 포맷팅 해주는 기능 제공. 서로 다른 국가나 언어권마다 날짜를 표기하는 방식이 다르기 때문, 이를 일일이 수동으로 처리하지 않고 사용자의 환경이나 지정한 언어에 맞게 자동으로 변환할 때 유용하게 쓰임.
- 채택 여부 : AI의 답변을 이해하고 확인했으나, 실제 코드에 해당 문법을 채택하지는 않았음.
